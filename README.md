PandaExpenseTracker 🐼

A simple expense tracker built with Python and Pandas.

Features

- Record daily expenses
- Calculate total and average expenses
- Find the highest and lowest expenses
- Check budget usage
- Sort expenses from highest to lowest

Technologies Used

- Python
- Pandas

How to Run

1. Install Pandas:
   pip install pandas
2. Run the Python file:
   ExpenseTracker.py
3. Enter your expenses and budget to see the results.

About

This is my beginner Python project created to practice Pandas, DataFrames, calculations, conditional statements, and sorting.
